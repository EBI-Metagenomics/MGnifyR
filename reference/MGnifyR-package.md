# `MGnifyR` Package.

`MGnifyR` fetches data from the EBI MGnify database into R. Browse
studies with [`searchStudies`](searchStudies.md) and fetch their
taxonomic profiles as `TreeSummarizedExperiment` with
[`fetchStudies`](fetchStudies.md). See the vignette for an introduction,
[About MGnify](https://www.ebi.ac.uk/metagenomics/about) for general
MGnify information, and [API
documentation](https://www.ebi.ac.uk/metagenomics/api/v2/) for details
about MGnify API v2.
