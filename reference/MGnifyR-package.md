# `MGnifyR` Package.

`MGnifyR` implements an interface to the EBI MGnify database. See the
vignette for a general introduction to this package. [About
MGnify](https://www.ebi.ac.uk/metagenomics/about) for general MGnify
information, and [API
documentation](https://emg-docs.readthedocs.io/en/latest/api.html) for
details about the JSONAPI implementation.
